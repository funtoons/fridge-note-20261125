A program that writes one funny passive-aggressive note a smart fridge leaves
for its owner, to `/output/entry.txt` (1–200 characters, UTF-8).

Entry for the [Notes From a Passive-Aggressive Fridge](https://make.fun/bounty/u-motasimfuad-notes-from-a-passive-aggressive-fridge-83c00ad7)
bounty on [make.fun](https://make.fun).

## Run

```sh
node main.ts
```

Writes the note to `/output/entry.txt`. Deterministic and offline: no
randomness, no network, no timestamps — two runs produce byte-identical
output.
